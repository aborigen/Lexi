
# Lexi.AI - Version History

## v2.12.0 (2024-06-20)
### UX
- **Interactive Tutorial**: Added an animated finger guide that shows new players how to connect letters.
- **Context-Aware**: The guide intelligently picks a word from the current level to demonstrate.

## v2.11.0 (2024-06-18)
### Content
- **Massive Update**: Integrated 44 new Russian levels featuring iconic verses from *Eugene Onegin*.
- **Hint Refinement**: Optimized citation display for multi-line poetry in the mobile overlay.

## v2.10.0 (2024-06-15)
### Architecture
- **JSON Migration**: Levels are now decoupled from code and stored in structured JSON files for English and Russian locales.

## v2.9.0 (2024-06-12)
### UI & Interaction
- **Polished Entry Effects**: Added unique CSS animations for level loading (Slide-in and Zoom).
- **Hint Overlay**: Replaced inline hint text with a centered, high-contrast Dialog for mobile-first legibility.
- **Functional Rankings**: Activated the global leaderboard system via Yandex Games SDK.
