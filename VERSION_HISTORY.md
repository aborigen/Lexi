
# Lexi.AI - Version History

## v2.28.0 (2024-07-20)
### UI Refinement
- **Letter Ring Alignment**: Optimized the circular letter interaction by rotating the ring to a 45-degree start, providing a cleaner geometric layout for the interaction engines.

## v2.27.0 (2024-07-19)
### Social & Competitive Refinement
- **Leaderboard 2.0**: Completely refactored the leaderboard data algorithm for better performance and accuracy.
- **Self-Identity**: The ranking system now clearly highlights the player's own position using secure ID matching.
- **Resilience**: Added automated retries and better error boundaries for SDK network requests.

## v2.26.0 (2024-07-18)
### UI/UX Polish
- **Toast Refinement**: Improved toast notifications with glassmorphism and a primary-colored glow.
- **Safe Zones**: Repositioned notifications to ensure no overlap with the game score or header controls.

## v2.25.0 (2024-07-17)
### New Features
- **Level Navigation**: Added a "Skip Level" button (`SkipForward` icon) to the header for easier testing and gameplay.
